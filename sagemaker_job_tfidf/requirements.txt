# Deliberately empty of packages.
#
# An earlier version pinned scikit-learn>=1.5 here so the pickled pipeline
# would match the >=1.5 the API unpickles it under. On the scikit-learn image
# that pulled numpy 2.x into a Python 3.9 environment whose compiled sklearn
# extensions were built against numpy 1.x, and the job died on import:
#
#   RuntimeError: CPU dispatcher tracer already initlized
#   ImportError: numpy._core.multiarray failed to import
#
# The pin meant to prevent a version mismatch caused a worse one. The job now
# runs on the same PyTorch py312 image the embedding job uses -- already proven
# in this account, and carrying a numpy and scikit-learn that agree with each
# other. Installing nothing is what keeps them agreeing; the exact versions are
# recorded in metrics.json rather than assumed.
